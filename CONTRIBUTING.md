# Contributing

Use Python 3.12+ and install `requirements-dev.txt`. Run `python -m pytest -q` before submitting a pull request. Keep Jenkins requests GET-only, URLs tied to the configured base, secrets server-side, and logs explicitly consented to before transmission.

Good first contributions: multilingual explanations, anonymized failure fixtures with expected evidence, improved log sampling, accessible frontend improvements, and a packaged Jenkins plugin. Do not commit real console logs, API keys, credentials, or PEM files. Document how a behavior was verified and label synthetic/demo results honestly.
